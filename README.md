# OLX deal watcher

Ищет объявления на OLX и подсвечивает те, что заметно дешевле медианы по такой же
категории/модели. Без браузера, без Selenium, без pip-зависимостей — только Python 3
и `curl`.

## Быстрый старт

```bash
# одиночный поиск, только сделки
python3 olx_watch.py --query "rtx 3060" --max-price 30000 --min-price 8000

# всё подряд, чтобы понять, что вообще есть
python3 olx_watch.py --query "rtx 3060" --all

# по конфигу (несколько поисков сразу)
python3 olx_watch.py --config config.json

# только новое с прошлого запуска + отправить в Telegram
python3 olx_watch.py --config config.json --new-only --tg

# показать всё, включая уже виденное (в т.ч. поверх --new-only из run.sh)
./run.sh --repeat
```

Сайты: `--site ua|kz|pl|ro|uz|bg|pt` (по умолчанию `ua`).
Вывод в JSON: `--json`. База «уже видел»: `seen.db` рядом со скриптом.

`найдено: N` — сколько подходящих объявлений вообще, `новых: M` — сколько из них
ещё не было в базе. С `--new-only` в таблицу попадают только новые, но их число видно
в шапке; если новых нет, скрипт так и пишет: `новых нет — всё уже видели`.
С `--repeat` показывается всё, а в Telegram всё равно уходят только новые.

## Релевантность (важно)

OLX ищет «мягко»: по запросу `rtx 3060` он отдаст ноутбуки, где в описании в куче
ключевых слов затесались `rtx` и `3060`. Поэтому скрипт сам проверяет выдачу:

- `--match all` (по умолчанию) — в тексте должны быть **все** слова запроса;
- `--match any` — хотя бы одно;
- `--match off` — доверять выдаче OLX как есть;
- по умолчанию слова ищутся **только в заголовке** (продавцы спамят моделями в
  описании); `--desc` — искать ещё и в описании.

Сколько отсеялось — скрипт пишет в шапке: `отсеяно нерелевантных: 30`.

## Как считается «сделка»

1. У каждого объявления берётся цена из параметров.
2. Определяется категория по заголовку: `видеокарта`, `ноутбук`, `пк`, `консоль`,
   `тв-бокс`, `телефон`, `планшет`, `тв`, `аксессуар`.
3. Если в заголовке есть модель (`rtx 3060`, `i7-11800h`, `ps5`), сравнение идёт
   с медианой **по этой же модели в этой же категории**, иначе — по категории,
   иначе — по всей выборке.
4. `🔥` — цена ≤ 75% медианы (`--threshold`), `⚠️` — ≤ 15% медианы (похоже на
   разводку или запчасть).

При этом «сделкой» объявление считается только если есть **с чем сравнивать**:
нужно минимум 2 объявления той же модели (`--min-peers`). Иначе дешёвый хлам
(«GTX 460 за 1 850») выглядел бы как скидка 50% просто потому, что он старый.

Дополнительно у поисков есть `require` — regex по заголовку, который отсекает древнее
железо: видеокарты ниже GTX 950 / RX 550, процессоры ниже 8-го поколения Intel.
Без этого медиана считалась по свалке и «сделки» были мусором.

Медиана считается по текущей выборке, поэтому **узкий запрос = точная оценка**.
Запрос «компьютер» даст кашу, «rtx 3060» — нормальную картину. Хочешь больше данных
для медианы — `--pages 3` (до 120 объявлений).

## Конфиг

```json
{
  "site": "ua",
  "searches": [
    {
      "name": "Игровые ПК",
      "query": "rtx 3060",
      "min_price": 8000,
      "max_price": 30000,
      "pages": 2,
      "match": "all",
      "desc": false,
      "must": ["rtx"],
      "exclude": ["куплю", "обмін", "на запчастини", "несправн"],
      "threshold": 0.75,
      "min_ratio": 0.15
    }
  ]
}
```

- `match` — `all` / `any` / `off`, как одноимённый флаг.
- `category_id` — фильтр по категории OLX: `101` консоли, `102` игры, `78` ПК,
  `80` ноутбуки, `458` комплектующие. Убирает мусор надёжнее слов.
- `desc` — `true`, если искать слова запроса ещё и в описании.
- `must` — хотя бы одно из этих слов должно быть в **заголовке**.
- `exclude` — стоп-слова (короткие ищутся по границе слова).
- `pages` — по 40 объявлений на страницу.
- Всё, что не указано в поиске, берётся из аргументов CLI.

## Telegram-бот: настройка с нуля

1. В Telegram найди **@BotFather** → `/newbot` → придумай имя и username.
2. BotFather выдаст токен вида `123456789:AAH...` — это `TELEGRAM_BOT_TOKEN`.
3. Открой своего бота и нажми **Start** (или напиши `/start`). Без этого бот не имеет
   права писать тебе первым.
4. Узнай свой `chat_id`:

   ```bash
   export TELEGRAM_BOT_TOKEN="123456789:AAH..."
   python3 olx_watch.py --tg-whoami
   # chat_id=123456789  (Имя)
   ```

5. Проверь отправку:

   ```bash
   export TELEGRAM_CHAT_ID="123456789"
   python3 olx_watch.py --tg-test
   ```

6. Боевой запуск:

   ```bash
   python3 olx_watch.py --config config.json --new-only --tg
   ```

В сообщение попадают только `🔥`-находки, максимум 15 штук, новые — первыми.

## Автозапуск (systemd --user)

На этой машине cron не запущен, поэтому стоит пользовательский таймер — каждые 15 минут:

```bash
systemctl --user status olx-watch.timer     # состояние и время следующего запуска
systemctl --user list-timers olx-watch.timer
systemctl --user start olx-watch.service    # запустить прямо сейчас
journalctl --user -u olx-watch.service -n 50  # лог
```

Файлы: `~/.config/systemd/user/olx-watch.{service,timer}`.
Остановить: `systemctl --user disable --now olx-watch.timer`.

Важно: без `loginctl enable-linger` таймер живёт только пока ты залогинен в систему.
После перезагрузки/входа он поднимется сам (таймер включён в `timers.target`).

Альтернатива, если появится cron:

```cron
*/15 * * * * /home/hoxs/olx-watch/run.sh >> /home/hoxs/olx-watch/watch.log 2>&1
```

## Ограничения

- API у OLX публичный, но неофициальный: формат может измениться, лимит выдачи ~1000
  объявлений на запрос. Для личного использования и низкой частоты — норм; не гоняй
  сотни запросов в минуту, иначе получишь 403.
- Python режется по TLS-отпечатку, поэтому запросы идут через `curl`. Если `curl` нет —
  скрипт упадёт с понятной ошибкой.
- Медиана — грубая эвристика. Хорошая цена ≠ хорошее состояние: читай описание и
  проверяй продавца руками.
